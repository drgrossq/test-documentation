### TC-CHCK-001

| Поле | Значение |
|------|----------|
| **ID** | TC-CHCK-001 |
| **Название** | Успешное оформление заказа с валидными данными |
| **Предусловия** | Пользователь авторизован как standard_user; в корзине есть товары; открыта страница Checkout: Your Information |
| **Шаги** | 1. Ввести "Ivan" в поле "First Name" <br> 2. Ввести "Ivanov" в поле "Last Name" <br> 3. Ввести "12345" в поле "Zip/Postal Code" <br> 4. Нажать "Continue" <br> 5. На странице Checkout: Overview нажать "Finish" |
| **Ожидаемый результат** | Отображается страница "Checkout: Complete!" с сообщением "Thank you for your order!"; заказ успешно оформлен |
| **Постусловия** | Сбросить состояние приложения через боковое меню |
