## BUG-INV-001

| Поле | Значение |
|------|----------|
| **ID** | TC-INV-001 |
| **Название** | Сортировка товаров по цене у пользователя problem_user не работает |
| **Связанный тест-кейс** | TC-LOGIN-021 |
| **Предусловия** | Пользователь авторизован как problem_user; открыта страница каталога |
| **Окружение** | Yandex Browser 26.6.2.960 (64-bit), Windows 10 Pro x86-64, Asus n56jrh |
| **Шаги** | 1. Выбрать сортировку "Price (low to high)" |
| **Ожидаемый результат** | При выборе "Price (low to high)" товары отображаются по возрастанию цены. При выборе "Price (high to low)" товары отображаются по убыванию цены. |
| **Фактический результат** | Сортировка по цене не работает ни в одном из направлений: при выборе "Price (low to high)" и "Price (high to low)" порядок товаров остаётся неизменным (исходным). |
| **Severity** | Major |
| **Priority** | Medium |
| **Status** | Open |
| **Логи** | ![запись-бага-1](/Bug_Reports/2_Bug_Reports_Inventory/assets/bandicam-2026-07-28-14-26-12-020_1.gif) |

## BUG-INV-003

| Поле | Значение |
|------|----------|
| **ID** | TC-INV-003 |
| **Название** | Нельзя удалить добавленный товар кнопкой "Remove" у пользователя problem_user |
| **Предусловия** | Пользователь авторизован как problem_ser; товары добавлены в корзину |
| **Окружение** | Yandex Browser 26.6.2.960 (64-bit), Windows 10 Pro x86-64, Asus n56jrh |
| **Шаги** | 1. Нажать кнопку "Remove" у добавленных товаров |
| **Ожидаемый результат** | После каждого нажатия кнопка "Remove" изменяется на "Add to cart"; счётчик корзины уменьшается на 1. По итогу всех шагов счётчик корзины = 0. |
| **Фактический результат** | Кнопка "Remove" не изменяется на "Add to cart" ни у одного из перечисленных товаров; счётчик корзины остаётся равным 3. |
| **Severity** | Major |
| **Priority** | Medium |
| **Status** | Open |
| **Логи** | ![запись-бага-2](/Bug_Reports/2_Bug_Reports_Inventory/assets/bandicam-2026-07-28-14-36-52-910.gif) |
