## BUG-CRT-001

| Поле | Значение |
|------|----------|
| **ID** | TC-CRT-001 |
| **Название** | Вёрстка кнопки "Checkout" смещена в корзине у пользователя visual_user |
| **Предусловия** | Пользователь авторизован как visual_user; |
| **Окружение** | Yandex Browser 26.6.2.960 (64-bit), Windows 10 Pro x86-64, Asus n56jrh |
| **Шаги** | 1. Добавить любой товар в корзину. <br> 2. Перейти в корзину добавленных товаров (/cart.html) |
| **Ожидаемый результат** | Кнопка "Checkout" расположена в правом нижнем углу страницы корзины, под списком добавленных товаров. |
| **Фактический результат** | Кнопка "Checkout" расположена в правом верхнем углу страницы; вёрстка смещена относительно штатного положения. |
| **Severity** | Minor |
| **Priority** | Low |
| **Status** | Open |
