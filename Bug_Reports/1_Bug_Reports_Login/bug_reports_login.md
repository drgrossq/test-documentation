## BUG-LOGIN-001

| Поле | Значение |
|------|----------|
| **ID** | BUG-LOGIN-001 |
| **Название** | Поле Username не обрезает начальные и конечные пробелы — при вводе логина с пробелами авторизация завершается ошибкой |
| **Связанный тест-кейс** | TC-LOGIN-009 |
| **Предусловия** | Открыта страница https://www.saucedemo.com/; пользователь не авторизован |
| **Окружение** | Yandex Browser 26.6.2.960 (64-bit), Windows 10 Pro x86-64, Asus n56jrh |
| **Шаги** | 1. Ввести ` standard_user ` (с пробелами до и после) в поле "Username"<br> 2. Ввести `secret_sauce` в поле "Password"<br> 3. Нажать кнопку "Login" |
| **Ожидаемый результат** | Начальные и конечные пробелы обрезаются автоматически, авторизация проходит успешно, осуществляется переход на страницу каталога (/inventory.html).  |
| **Фактический результат** | Авторизация не выполнена; отображается сообщение об ошибке "Epic sadface: Username and password do not match any user in this service". Пользователь получает неинформативное сообщение, которое не указывает на реальную причину ошибки — наличие лишних пробелов |
| **Severity** | Minor |
| **Priority** | Medium |
| **Status** | Open |

## BUG-LOGIN-005

| Поле | Значение |
|------|----------|
| **ID** | BUG-LOGIN-005 |
| **Название** | Отсутствие rate limiting на странице авторизации — неограниченное количество неудачных попыток входа без блокировки |
| **Связанный тест-кейс** | TC-LOGIN-030 |
| **Предусловия** | Открыта страница https://www.saucedemo.com/; пользователь не авторизован |
| **Окружение** | Yandex Browser 26.6.2.960 (64-bit), Windows 10 Pro x86-64, Asus n56jrh |
| **Шаги** | 1. Ввести неверные учётные данные и нажать "Login" — повторить 5 раз подряд<br> 2. На 6-й раз ввести `standard_user` / `secret_sauce` и нажать "Login" |
| **Ожидаемый результат** | После серии неудачных попыток применяются защитные механизмы: CAPTCHA, временная блокировка аккаунта/IP, прогрессивное увеличение задержки ответа, или уведомление о превышении лимита попыток. |
| **Фактический результат** | После 5 последовательных неудачных попыток входа не применяются никакие защитные механизмы: отсутствует CAPTCHA, отсутствует блокировка IP/аккаунта, отсутствует прогрессивная задержка (время ответа стабильно ~500 ms на каждой попытке), отсутствует уведомление о лимите попыток. На 6-й попытке с валидными данными `standard_user` / `secret_sauce` авторизация проходит немедленно и успешно — без каких-либо ограничений или предупреждений. Система полностью открыта для brute-force атак |
| **Severity** | Critical |
| **Priority** | High |
| **Status** | Open |
| **Логи** | ![ошибка-5](/Bug_Reports/1_Bug_Reports_Login/assets/bandicam-2026-07-27-15-56-27-484.gif) |
